# Real-World quiz answers

Expected answers from the English question bank, with qualifications where the lesson simplifies a concept.

## Quiz 49: Real World Applications: Pre-Lecture Quiz

1. What's an example of an ML application in the Finance industry?  
   **Answer:** Wealth management using linear regression  
   Regression can relate fund returns to a benchmark; this is the lesson example, not a recommendation about investments.
2. What ML technique can hospitals use to manage readmission?  
   **Answer:** Clustering  
   Clustering can describe groups of readmissions, but does not by itself establish clinical causes or validate patient risk predictions.
3. What is an example of using Time Series for energy management?  
   **Answer:** Smart parking meters  
   This is the repository answer. Parking demand is one forecasting example; the executed energy prototype instead predicts electricity load.

## Quiz 50: Real World Applications: Post-Lecture Quiz

1. Which ML technique can be used to detect credit card fraud?  
   **Answer:** Clustering  
   Unusual transaction clusters can support investigation. Outliers are not automatically fraud.
2. Which ML technique is exemplified in forest management?  
   **Answer:** Reinforcement Learning  
   This is the application associated with forest management in the lesson.
3. What's an example of an ML application in the Health Care industry?  
   **Answer:** Managing clinical trials using classifiers  
   The lesson describes a classification use case; it is not evidence that the portfolio model is suitable for clinical use.

The English question bank contains no separate quiz entries for the model-debugging postscript. No additional quiz answers are invented.
