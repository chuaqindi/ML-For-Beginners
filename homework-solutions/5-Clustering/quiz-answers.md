# Clustering quiz answers

Expected answers for English quiz IDs 27–30, with clarifications.

## Quiz 27: Introduction to Clustering: Pre-Lecture Quiz

1. A real-life example of clustering would be  
   **Answer:** Sorting the laundry  
   Sorting items by similarity illustrates grouping without a supplied target label.
2. Clustering techniques can be used in these industries  
   **Answer:** both of these  
   Clustering can support exploratory segmentation in multiple domains; the groups still need validation.
3. Clustering is a type of:  
   **Answer:** unsupervised learning  
   Clustering discovers a partition without learning from target labels.

## Quiz 28: Introduction to Clustering: Post-Lecture Quiz

1. Euclidean geometry is arranged along  
   **Answer:** planes  
   The quiz refers to flat Euclidean space; distances and geometry influence the resulting groups.
2. The density of your clustering data is related to its  
   **Answer:** noise  
   The quiz links density and noise; more precisely, density-based methods can label sparse regions as noise.
3. The best-known clustering algorithm is  
   **Answer:** k-means  
   K-Means is a widely used centroid-based method, though suitability depends on geometry.

## Quiz 29: K-Means Clustering: Pre-Lecture Quiz

1. K-Means is derived from:  
   **Answer:** signal processing  
   This is the historical connection used in the lesson.
2. A good Silhouette score means:  
   **Answer:** clusters are well-separated and well-defined  
   A larger silhouette usually indicates greater cohesion and separation in the chosen metric space.
3. Variance is:  
   **Answer:** both of these  
   Variance summarizes squared deviations around a mean; scale differences affect Euclidean distances.

## Quiz 30: K-Means Clustering: Post-Lecture Quiz

1. A Voronoi diagram shows:  
   **Answer:** a cluster's seed and its region  
   Each region contains points nearer its seed than the other seeds under the chosen distance.
2. Inertia is  
   **Answer:** a measure of how internally coherent clusters are  
   For K-Means, inertia is the sum of squared distances to assigned centroids.
3. Using K-Means, you must first determine the value of 'k'  
   **Answer:** true  
   K-Means requires a chosen number of clusters; elbow and silhouette diagnostics can inform the choice.
